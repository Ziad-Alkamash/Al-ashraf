Verse timestamp data in this directory is adapted from QUD-Technologies' Quranic Universal Audio dataset, release v3.2.0.

Source: https://github.com/QUD-Technologies/quranic-universal-audio/releases/tag/v3.2.0
License: Creative Commons Attribution 4.0 International (CC BY 4.0).

The compact JSON rows are [surah, ayah, start_ms, end_ms]. The associated MP3Quran chapter audio URLs are the same source URLs recorded in that release's reciter catalog. Recitations with incomplete source coverage only contain rows provided by the dataset.
